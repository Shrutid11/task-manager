# Task Manager App

A modern full-stack **Task Manager application** built using **Next.js**, **MongoDB**, **Mongoose**, **Tailwind CSS**, and **shadcn/ui**. This application allows users to create, organize, update, and manage projects and tasks through a clean and responsive interface.

## 🚀 Features

* Create and manage projects
* Create tasks under different projects
* Update task details
* Delete tasks and projects
* Organize tasks using categories
* Track task status
* Responsive user interface
* RESTful API routes
* MongoDB database integration

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Shrutid11/task-manager.git
```

### 2. Navigate to the project

```bash
cd task-manager
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create environment variables

Create a `.env.local` file in the root directory:

```env
MONGODB_URI=your_mongodb_connection_string
```

### 5. Run the application

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
